A plugin to assist the Prime Number Map Challenge for streamers, 
or for anyone that wants to play prime number maps. 
Remembers last Map ID Loaded, persistent through Trackmania restarts. 
One Click increments the prime number and loads the map. 
If the Map ID does not exist, will automatically tries the next prime number. 
Enter a Map ID to Load, or to use as a starting point to generate the next prime.
